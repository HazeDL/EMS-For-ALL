Как правильно выдавать таблетки

Для выдачи таблеток вам понадобятся кодеиновые таблетки. Максимальное количество за одно взятие — 48 кодеиновых таблеток.

📦 Что нужно для выдачи

Для выдачи таблеток вам понадобятся кодеиновые таблетки. Максимальное количество за одно взятие — 48 кодеиновых таблеток.

📍 Где стоять интернам

Для выдачи таблеток интернам необходимо находиться у стойки в отделении скорой помощи. Пример:

💰 Выдача таблетки гражданину

Для выдачи таблетки гражданину необходимо нажать:

G › Фракционное › Продать таблетку

Стоимость таблетки: зависит от уровня игрока, которому вы даёте таблетку.

Для обычного игрока: 100$
Для игрока высокого уровня: 300$
🏥 Гос. сотрудникам — бесплатно

Для гос. сотрудников таблетки являются бесплатными. Сначала просим сотрудника показать удостоверение или жетон. Далее нажимаем:

G › Фракционное › Вылечить игрока
